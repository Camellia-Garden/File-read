# 纸间 · TXT 阅读器

纸间是一个日系插画风格的本地 TXT 小说阅读器。

双击打开 `index.html` 即可使用。可以先打开内置示例《雨后的书店》，也可以点击 **导入 TXT** 或将文件拖进书架。支持一次导入多本。

- 自动识别常见中文章节标题，支持在目录中跳转。较长正文会分节显示，可用左右方向键切换，按 Esc 回书架。
- 自动识别 UTF-8、带 BOM 的 UTF-16 和 GB18030 / GBK。在阅读设置里可以手动选择编码，也支持 Big5 与 Shift JIS。
- 可调字号、行距和宋体 / 黑体，提供日间、护眼和夜间三种主题。
- 书籍、设置和阅读进度保存在当前浏览器，文件内容不会上传。建议用同一个浏览器、同一个入口打开；清理网站数据会清除已导入的书籍和进度。

整个项目是静态网页，适合直接用静态托管服务发布。
